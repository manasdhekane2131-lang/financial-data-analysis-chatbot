# Financial Data Analysis & Rule-Based Chatbot Prototype

A financial analysis and rule-based chatbot prototype developed as part of the BCG X GenAI Job Simulation.

## Overview

This project focuses on analyzing financial data of Microsoft, Tesla, and Apple for the years 2023–2025 and developing a simple rule-based financial chatbot using Python.

## Technologies Used

- Python
- Pandas
- Jupyter Notebook

## Companies Analyzed

- Microsoft
- Tesla
- Apple

## Financial Metrics

- Total Revenue
- Net Income
- Total Assets
- Total Liabilities
- Cash Flow from Operating Activities

## Chatbot Features

- Predefined financial queries
- Rule-based if-elif-else logic
- Financial data responses
- Basic error handling
- Query testing

## Project Outcome

The project provided practical experience in financial data analysis, Python programming, and developing a basic chatbot prototype for business use cases.
